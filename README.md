# Памятка статей расхода

Статический проект для GitHub Pages: интерактивное дерево выбора статьи расхода.

## Файлы

- `index.html` — структура страницы.
- `style.css` — внешний вид и адаптация под мобильные устройства.
- `app.js` — логика переходов, кнопки назад/заново/копировать/поделиться.
- `data.js` — вопросы, варианты ответов и итоговые результаты.

## Как обновлять тексты

Обычно нужно менять только `data.js`.

Внутри каждого вопроса есть:

```js
{
  type: "question",
  question: "Текст вопроса",
  options: [
    {
      label: "Текст варианта ответа",
      next: "id-следующего-узла",
      icon: "dots"
    }
  ]
}
```

Итоговый результат выглядит так:

```js
{
  type: "result",
  title: "Текст результата",
  status: "ready"
}
```

## Важно

Вопросы, варианты и результаты должны повторять формулировки из исходной блок-схемы. Не добавляйте пояснения в `hint`, `description` или другие дополнительные поля, если их нет в схеме.

## GitHub Pages

Для публикации:

1. Загрузите файлы в корень репозитория.
2. Откройте `Settings` → `Pages`.
3. Выберите `Deploy from a branch`.
4. Branch: `main`, folder: `/(root)`.
5. Нажмите `Save`.
