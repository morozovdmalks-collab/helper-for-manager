# Памятка статей расхода

Готовая статическая web-страница для выбора статьи расхода по дереву решений из Visio-схемы.

Проект можно открыть:

- как обычную web-страницу в браузере;
- как Telegram Mini App, если указать URL этой страницы в настройках бота.

## Состав файлов

```text
index.html   — разметка страницы
style.css    — внешний вид и анимации
data.js      — вопросы, варианты ответов и итоговые статьи
app.js       — логика выбора ответов
favicon.svg  — иконка сайта
.nojekyll    — служебный файл для GitHub Pages
```

## Как запустить на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы из этой папки в корень репозитория.
3. В настройках репозитория включите GitHub Pages для ветки `main` и папки `/root`.
4. После публикации откройте ссылку вида:

```text
https://ваш-логин.github.io/название-репозитория/
```

## Как редактировать вопросы и ответы

Вся логика дерева лежит в файле `data.js`.

Чаще всего нужно менять только поля:

```js
question: "Текст вопроса"
label: "Текст варианта ответа"
description: "Описание варианта или результата"
title: "Название итоговой статьи"
code: "Код статьи"
```

Не меняйте `id` узлов и значения `next`, если не уверены, потому что они связывают варианты ответа со следующими вопросами.

## Telegram Mini App

Страница уже содержит безопасную проверку Telegram WebApp API. Если открыть её в обычном браузере, она работает как обычный сайт. Если открыть внутри Telegram, она определит режим Mini App и сможет отправить итог обратно в Telegram через кнопку «Отправить в Telegram».

Для полноценной отправки результата в чат нужен Telegram-бот с обработкой данных Mini App на стороне бота.

## Важное замечание по доступу

Если проект размещён на GitHub Pages в публичном репозитории, страницу и данные можно считать публичными. Не размещайте здесь конфиденциальные внутренние данные, если доступ должен быть ограничен.

## Обновление v1.4

Добавлено:
- поиск по итоговым статьям;
- кнопка «Сообщить об ошибке» на экране результата;
- при сообщении об ошибке текст обращения копируется в буфер, после чего открывается Telegram-группа;
- скрыта системная кнопка Telegram Mini App «Готово», так как она не использовалась.

Важно: браузер и Telegram Mini App не могут автоматически отправить сообщение в приватную группу без backend/бота. Поэтому кнопка копирует готовый текст и открывает группу, где пользователь вставляет сообщение и дописывает комментарий.
